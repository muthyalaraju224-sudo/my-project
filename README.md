# my-project

A small sample project used to try out Claude Code GitHub Actions integration. Mention @claude in an issue or pull request to have it help with changes.


## How to use

1. **Open an issue or pull request** in this repository.
2. **Mention `@claude`** in the description or a comment, followed by what you want done.
3. **Review the result** — Claude replies in the thread and pushes its changes to a branch for you to review and merge.
